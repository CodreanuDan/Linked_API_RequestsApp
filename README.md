# Linked API Request App

## Overview
This project is a tourist application that retrieves and processes data via API requests. It provides useful information about trips, including:
- **AI-generated travel insights** – Uses Gemini AI to generate a description of the city and the user's main activity.
- **General location info** – Displays key facts about the destination.
- **External references** – Provides links to Google Maps and Wikipedia.
- **Weather forecast** – Retrieves a 7-day weather forecast.
- **Route planning** – Calculates the driving route, distance, and estimated duration.

The app is built in **Python** using **Streamlit** for the UI, with **HTML & CSS** enhancements for a visually appealing experience.
